# Code of conduct

Contributors and maintainers are expected to treat others with respect, invite constructive criticism, and make participation accessible. Disagree with ideas using evidence and focus discussion on the work.

Harassment, threats, discrimination, unwanted sexual attention, and sharing another person's private information without consent are unacceptable in project spaces. Do not use project channels to threaten or target people outside the project.

Maintainers may edit or remove harmful material, limit participation, or take other action proportionate to the behavior. Report concerns to a maintainer through a private channel available on their GitHub profile. GitHub also provides reporting controls for content or conduct on its platform.

Maintain privacy when reporting or handling an incident. The code of conduct applies to issues, pull requests, discussions and other interactions representing the project.
